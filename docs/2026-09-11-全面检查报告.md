## 一、这一轮修了什么（v11c → v11d）

| 项 | 做法 |
|---|---|
| 24 条低精度坐标 | 网络受限，只能走搜索→可抓取页面。**6 条拿到两个独立来源互证的坐标**（机场航站楼、WorkBC 北岸、Scotiabank、Mustard Seed、Westsyde 的 Save-On 与 BC Liquor——后两条原来标在广场以南约 950 m，已纠正）。其余 18 条只有单一目录来源（bc211 / yably），与现值一致但无法互证，**保留"大致位置"标记**，弹窗仍会提示，导航按钮用地址不用坐标，所以"去"是对的，"在图上找"可能偏。这 18 条需要有人在真机地图上落点，是目前数据层唯一靠代码解决不了的事 |
| HTML 安全头 | Worker 给每个静态响应加：CSP（锁定脚本/图片/连接来源、禁止被嵌入、禁 object/base）、`X-Content-Type-Options`、`Referrer-Policy`、`X-Frame-Options`、`Permissions-Policy`、`COOP`。CSP 保留 `'unsafe-inline'`（单文件内联脚本与 onclick），所以它防的是"从别处加载/发往别处"，不防内联注入。用完全相同的 CSP 在本地 http 服务下跑过页面：零违规、Service Worker 正常注册 |
| `/api/event` 开放 + 无限速 | 只接受本站浏览器的请求（`Origin` / `Sec-Fetch-Site` / `Referer` 三者之一必须匹配本站；三者皆无——典型的 curl——拒绝 403）；每 IP 每分钟 120 条软限（边缘缓存计数，缓存故障时放行）；CORS 不再是 `*`。单元测试：同站 200、跨站 403、裸 POST 403、第 121 条 429、其他 IP 不受影响。`deploy.sh` 的探针相应带上 Origin，并新增"跨站应 403""首页应有 CSP"两条 |

| 兼容性（复查发现） | `.backdrop{inset:0}` 在 iOS ≤14.4、旧 Android WebView、Samsung ≤13 上被忽略——**所有弹层会出现在页脚之后，读者只看到一片模糊**；改为四个方向长属性。`font:600 12px/1 inherit` 是非法简写（三处）——按钮一直在用浏览器默认字号；改为长属性 |
| 埋点（复查发现） | `js_error` 读的是不存在的 `ev.lineNumber`，行列号永远是 0，且不带版本——改读 `lineno/colno`，附堆栈前三行和 `DATA_VERSION`；`task_open` 只在列表点击时发，从弹窗/深链接/进度条/搜索交接进入卡片的都没有——改在 `openTask` 内统一发并带 `src` |
| 静态元信息 | `<title>`、`og:title/description`、`theme-color` 还是"Kamloops Living Services Map"和旧蓝——爬虫和分享卡片看到的是旧名字；改为 Life Guide 与新色 |

## 二、按维度的结论

### UI
已对齐 Apple 系统灰阶、分组背景、AA 合规蓝、胶囊控件、柔和阴影、半透明浮动条、底部 sheet。**未修**：emoji 当图标（与 Apple 差距最大的一项，需一套约 30 个单色 SVG）；正文字号整体偏小一档（改字号会动全部布局基线，单独一轮）；四个筛选按钮并排（Apple 会收成一个"筛选"+ sheet，涉及回归里大量按钮选择器）；分类色 12 种饱和色（Apple 是 6 个柔和色族 + 符号）；`color-mix()` 在 iOS 15–16.1 / Chrome <111 上整条声明失效，芯片会没有边框与底色——可用但难看，需要 41 处 rgba 兜底。

### 交互逻辑
sheet、Back 手势、导航栈、撤销、按压反馈、统一选中态均已落地并经独立复查。**未修**：底部标签栏（占 56px，破 40% 地图底线）；Apple Maps 式地点卡替代气泡（三十余项回归围绕气泡）；`?task=` 深链接三次 Back 才离开。

### 日志与埋点
40 种事件、79 处埋点、无 console 噪音。修了 `js_error` 与 `task_open`。**未修，且重要**：Analytics Engine 的 schema 把所有属性塞进一个 JSON blob，AE 没有 JSON 函数——语言、传单来源、分享渠道、类别、卡片 id 都**无法 GROUP BY**，只能 LIKE 扫描。要把 `lang / id / src / cat / host` 提升为独立 blob 列（改 worker 一处 + 客户端信封两处），否则商业化需要的曲线画不出来。缺 `appinstalled`、离线使用、`session_end`；`sid` 永不轮换（隐私上建议 90 天轮换）。

### 多语言
六语键完整、无回退、无占位泄漏。日期语法映射只覆盖六语，第七种语言会落到西语日期格式；RTL 完全未考虑（59 处物理左右属性）。旁遮普语仍是最值得加的第七种。

### 界面一致性与及时性
弹窗打开时重建、换语言全量重绘。**未修**："现在营业"和截止日倒计时只在交互时重算（页面挂一夜不会自己更新；加一个 `visibilitychange` 重算即可）；`VERIFIED='2026-08-30'`、`DATA_VERSION`、每条 `v` 三个时钟手工维护，validate 不校验 `VERIFIED`；数据说明里说"改动记录在版本号里"但页面上没有任何地方显示版本号。

### 数据
287 处、11 条隔离、六语备注齐全、无坏时间行、区域与坐标一致。剩余风险就是上面的 18 条大致坐标，以及 52 条深层链接会腐烂（需在有网的机器上跑 `check-links.py`）。

### 法律与隐私
声明三层齐全、承诺与代码一致、5 个工作日下架、"无可识别数据故无从删除"。**未修**：署名与许可仍在自然人名下（商业化前要换法人）；`CC BY-NC` 对"雇主分发"只说"来信问"，机构版需要明确许可条款；律师过目。

### 设计合理性 / 首次使用 / 内容缺失
指南优先已成立（首屏唯一实心蓝是指南；副标题写明给谁；搜索框接问句；首次卡说明免费无注册）。内容缺口：walk-in 诊所是城市事实；宗教场所缺印度教/东正教/非英语教会；Westsyde 仍薄；机构照片/门脸照片没有（亲切感的下一步）。

### 兼容性（手机 / 平板 / 电脑）
语法底线 ES2017（Safari 10.1+ / Chrome 55+ 不白屏）。修了 `inset` 与 font 简写。平板：≤900px 走 sheet，>900px 走对话框——竖持平板是 sheet、横持是对话框，均已实机（Playwright 820×1180 / 1180×820）验证。**未修**：`color-mix` 兜底；flex `gap` 在 iOS ≤14.4 塌陷（布局挤在一起，可用）；微信内置浏览器里 `mailto:` 与 `.ics` 下载无反应且无提示。

### 商业化预埋
有 CSS 变量作主题钩子，但缺：机构版的品牌/署名位、按类别/区域限定的"范围"配置、分开的联系邮箱、事件信封里的 `host/edition` 列（多部署无法区分）、`build.py --edition` 叠加层、`frame-ancestors 'none'` 会挡住机构内网嵌入（需要时对白名单放开）。这些都是数据字段与构建脚本的事，不需要分叉代码。

### 扩城市 / 扩国家
最大的结构性问题：**14 张办事卡（TASKS）住在引擎里，而且是 Kamloops 专属**（地点 id、SD73、ICBC、250- 电话），validate 也不扫它——"引擎不含城市事实"这条纪律实际上没被执行。第二座 BC 城市 = 数据文件 + 约 10 处引擎改动（TASKS 迁入数据层、页脚电话、票价、时区、存储键前缀、head/manifest/sw 生成）；第二个省 = 再加 `guideProv`×6、约 8/14 张卡、截止日规则、热线、适用法律；第二个国家 = 再加 `guideCA*`×6、电话/地址/货币/日期表、许可。建议下一轮先做"TASKS 迁入数据层 + validate 扫 TASKS"，这是扩展的第一块砖。

## 五、快捷选择：手机上的方案（v2026.09.11f）

**问题**：快捷选择一行 14 个胶囊，390px 手机一屏只露 3 个，第 6 个以后从未被滑到；其中后 7 个（亲子场所、教育、医疗、运动健身、户外探索、购物采购、交通）本质是"分类组合"，与工具栏的"分类"按钮重复。

**做法**（方案 1 + 2 + 3 叠加）：

| 项 | 做法 |
|---|---|
| 精简为场景 + "更多" | 行内只留场景：遇到问题怎么办、日常必备、居民必备、免费低价、亲子遛娃、现在营业（冬季加"冬天室内"），末尾一个虚线的"更多 ›"，点开就是分类 sheet。7 个分类组合整块搬到分类 sheet 顶部（"🎯 一键选一组"），同样的胶囊、同样的 id、同样的行为，不用重新学 |
| 按情境排序 | `quickPickOrder(ctx)` 是纯函数：17:00 后或周日"现在营业"排第二；周末"亲子遛娃"上移；11–3 月出现"冬天室内"（其他月份不在行内，但主题里打开它时会出现）；从传单/名片扫码进来（`?src=flyer-*`/`card-*`）"居民必备"紧随指南；第 3 次访问起（`kamloopsVisits` 本地计数，上限 999）"居民必备"退到主题之后。指南永远第一，"更多"永远最后。时钟部分在一次会话内冻结（回到标签页时刷新），不会在 17:00 那一刻在拇指下重排 |
| 滑动手感 | `scroll-snap-type:x proximity`，一甩停在整颗胶囊上；原有的渐隐 + › 继续提示"右边还有" |
| 桌面 | 7 个一行放得下，无需滑动；"更多"点击不再被"点在面板外"逻辑误判为关面板 |
| `sid` 轮换（上一份报告唯一未修项） | id 与生成日期一起存，超过 90 天换新；旧浏览器里已有的 id 从今天开始计时而不是立刻作废。`session_start` 新增 `visits` |

**验证**：`quickPickOrder` 六组情境断言；"更多"在手机与桌面均打开分类 sheet 且组合区在最上；组合芯片在 sheet 内仍能一键选中并保持 sheet 打开；`sid` 轮换与访问计数；320/390/820/1366 五种语言无横向溢出、地图占比 55–64%。全套回归（含新增 10 项）零失败后提交。
