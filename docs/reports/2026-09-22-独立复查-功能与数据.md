# 独立复查：功能与数据（2026-09-22）

这次检查不以今天之前的任何改动或报告为前提，从头重新做了一遍。

核对的原则是：**不只看链接能不能打开，要看打开后的内容是否对得上**。每一条都拿权威来源逐项比对，包括名称、电话、地址、坐标、时间和数字。只有两个以上独立来源一致、而我们的数据与之不符时，才判定为错误并修改。

## 一、核对方法与来源

| 对象 | 比对来源 | 做法 |
|---|---|---|
| 公交 14 条线路 | BC Transit 官方当期 GTFS 时刻表（2026-09-19 起生效） | 逐条核对线路名、颜色、每个站名、站点坐标（误差不超过 80 米）、首班和末班时间 |
| 292 个地点的位置 | BC 省政府地址库（BC Address Geocoder）、OpenStreetMap、Google 地图定位 | 先用省地址库查全部地址，偏差大的再用另外两个来源确认 |
| 239 个地点网站 | 网站本身 | 程序抓取后，服务器打不开的用无头浏览器渲染，还打不开的在你的 Chrome 里人工打开。逐个检查页面上是否有我们登记的**电话、门牌号和名称** |
| 17 张办事卡 | 各卡引用的官方原文，以及 CRA、HIBC、bc211、Interior Health 的相关页面 | 逐条核对期限、电话、表格编号、营业时间、资格条件 |
| 庇护所信息 | bc211 机构条目、BC Housing 文件、CMHA、ASK Wellness、市政府 2025 年冬季应对备忘录 | 核对床位数、电话、地址、入住方式 |
| 营业时间逻辑 | 用 Python 独立重写"是否营业"的判断规则 | 全部 292 个地点 × 一周每半小时，与页面结果逐一比对 |
| 法定假日 | 按 BC 法定假日规则推算 | 2026–2028 年逐日核对 |
| 功能 | 新写的独立测试 `tests/audit7.py`，共 28 项 | 覆盖 6 种语言下的筛选、搜索、营业状态、地点卡片、办事卡、公交、分享链接、收藏、求助面板、指南和多语言字符串 |

## 三、发现并已修复的错误

### 1. 公交末班时间（11 条线路）——影响最大

原数据里的"末班"取自 **12 月 31 日跨年夜才开的加班车**，平常根本没有这么晚的车。现已改为常规服务的最后一班：

| 线路 | 原写 | 改为 |
|---|---|---|
| 1 Tranquille | 次日 02:09 | 次日 01:14 |
| 2 Parkcrest | 次日 01:34 | 22:33 |
| 3 Westsyde | 次日 01:14 | 次日 00:16 |
| 4 Pacific Way | 次日 01:31 | 次日 00:07 |
| 5 Pineview | 次日 00:51 | 23:21 |
| 6 Downtown Loop | 次日 00:41 | 22:03 |
| 7 Aberdeen | 次日 02:25 | 次日 01:50 |
| 13 Yellowhead | 次日 01:43 | **20:46** |
| 14 Batchelor Heights | 次日 00:50 | **20:56** |
| 16 Juniper Ridge | 次日 01:24 | **20:22** |
| 17 Dallas | 次日 01:49 | 次日 00:04 |

9、10、18 路原本就是正确的。页面上"含周末延时班次"的说明依然成立：9 路周六的末班到次日 02:16。

### 2. 地点在地图上的位置（21 个）

判定依据：BC 省地址库、OpenStreetMap、Google 地图三方彼此相差不到约 130 米，而我们的点与它们相差 0.3–4.8 公里。

- 偏得最远的：Kamloops Kidz 托儿所（4.8 公里）、Columbia Manor（4.4 公里）、Windsor Plywood（3.6 公里）、DriveHub（3.6 公里）、TteS 行政办公室（3.4 公里）、All Aboard 托儿所（3.3 公里）、Secwepemc 博物馆（2.9 公里）。
- 其余：Central Apartments、Dufferin Terrace、Valleyview Manor、The View、Sacred Heart 大教堂、佛教寺、锡克文化协会、机场班车、Colour My World、Apex、KAFS、CCRR、日裔文化中心、Chevron Westsyde。
- **所属区域跟着改的有 6 个**：
  - Windsor Plywood → Sahali/Aberdeen
  - Columbia Manor → South Kamloops
  - 机场班车、DriveHub → Brocklehurst
  - 博物馆、TteS → Valleyview（与同在保留地上的 Powwow Trail 一致）
- **"位置为估计"标记**：已经三方确认的，去掉了这个标记；TteS 只有街区级精度，保留标记。
