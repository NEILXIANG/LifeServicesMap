## 二、结论

**翻译本身没有发现错误。** 6,747 条里：电话号码全部一致；HTML 标签全部闭合；模板占位符全部一致；没有漏翻；没有混入其他语言的文字；日文中没有简体字，中文中没有日文汉字。数字差异全部核对过，都是正确的本地化（"9 PM"→"21 h"、"210 ft"→"64 m"、"98,000"→"9.8万"）。

**语言识别和切换全部正确**：29 项全部通过（繁体中文浏览器显示简体中文；没有译文的语言显示英文）。

实际发现并修复的问题有 6 个，其中 **1 个是可能导致整页白屏的严重问题**，1 个是慢速手机上会让地图状态错乱的问题。

## 三、发现并修复的问题

### 1. 【严重】旧浏览器整页白屏的风险（p30）
今天早些时候（p22）我在同义词索引里用了 `\p{L}` 这种正则写法，它属于 ES2018，而本页面的语法底线是 ES2017。浏览器不认识这种写法时，整段脚本解析失败，用户看到的是一张空白页。
- 修复：改为显式字符范围，修复前后同义词索引 1,046 项**逐字节相同**。
- 防复发：`validate.py` 新增第 21 项，应用脚本中出现 `\p{`、`?.`、`??`、后行断言、命名捕获组、无绑定 catch 任一写法都会构建失败。另用 JS 解析器按 ES2017 标准解析整页，0 错误。

### 2. 【较严重】慢速手机上地图状态错乱（p31）
测试中连续搜索时偶发一次报错；把 CPU 降到中端手机水平（×4）后，4 次运行有 2 次报错，**操作间隔 300ms 这种正常速度也会触发**，位置在"重置"或单一结果搜索之后。原因是地图聚合插件在缩放动画期间被增删标记，内部网格留下残缺条目。报错会让计数、空结果提示、地址栏停在上一次的状态。
- 修复：动画期间只记录每个标记应有的状态，动画结束立即落实；"忙"状态最长 1.5 秒自动解除；若仍然报错则捕获、让本次更新完成，并在空闲时重建聚合。
- 验证：同样条件 12 次运行 0 报错，结束时地图上的标记与筛选结果 100% 一致。
- 只在确有需要时才等：标记已在聚合中时，单结果搜索照旧立即交给插件定位（弹出卡片约 0.1 秒，与修复前相同）；只有当它的加入还在排队时才等动画结束。
- 这个问题与翻译无关，是在多语言测试的大量操作中暴露出来的。

### 3. 区域筛选按钮在 390px 手机上跑出屏幕（p32）
英、法、西、日四种语言里，区域名称后面的说明较长（如 "Sahali/Aberdeen (coteau au sud du centre-ville, siège de TRU) · 85"），按钮不换行，在最常见的 390px 手机上超出屏幕最多 70px，说明和数量被截掉。现在按钮内可以换行。

### 4. 求助热线条目在 320px 小屏上超出（p32）
条目可以换行了，但电话号码本身永不断开。

### 5. 30 多个日常用词搜不到（p30）
每种语言输入约 60–90 个新居民会用的词，有 37 个返回 0 结果，但对应的地点其实存在。补充了同义词后只剩 13 个，且都是"确实没有"：
- 补上的例子：洗衣房、食品银行、邮政、溜冰场、室内游乐场、佛寺；barbier、tuteur；중고품、아시아마트、애견공원、가정의；お寺、韓国スーパー、車の修理、自動車学校。
- 指向单一机构的词写进该地点的别名：ESL / english class / 英语课 / cours d'anglais / 이민자 서비스 / 移民支援 / 英語教室 → Kamloops Immigrant Services（它的说明里本来就写了 LINC 英语课）；대학교 → TRU。
- 刻意没有加的：带空格的韩文组合词（如 "카 센터"）——搜索会按词拆开索引，"센터"单独出现就会把所有"中心"都指向汽车维修。测试里专门断言 센터、매장、식품、학원、école、parque 这些常用词的含义没有被改变。

### 6. 读屏播报停留在上一种语言（p30）
给视障用户朗读的"显示 387 / 387 处地点"在切换语言后仍保留上一种语言，直到数量变化才更新。现在切换语言时清空。视力正常的用户看不到这一项。

另：西语城市介绍里千位分隔符混用（"98,000" 与 "97.902" 同在一段），统一为点。

## 四、仍然存在、演示时需要知道的（均为设计如此，不是错误）

| 现象 | 原因 |
|---|---|
| 公交站名是英文（如 "Tranquille Rd at Palm St"） | 站牌上就是英文，翻译反而找不到站 |
| 地点名称、地址保持英文 | 同上，导航和问路都要用英文原名 |
| 搜"咖啡 / coffee / café / 커피 / カフェ"没有结果 | 数据里唯一的咖啡店已下架核实，没有就是没有 |
| 繁体中文浏览器显示简体中文 | 目前只有简体译文 |
| 旁遮普语、他加禄语、阿拉伯语、乌克兰语显示英文 | 尚未翻译，演示材料里已如实说明 |
| 日文或中文只输入一个字（如"薬"）时显示全部地点 | 单字太短不触发搜索，会提示再多输入一点 |
| 搜"无预约诊所"地点列表为空 | 但会弹出"今天要看病？"答案卡，指向北岸急诊中心，这是设计的行为 |
