## p27 气泡

| 审视里的问题 | 处理 |
|---|---|
| **P0** 导航 / 电话 / 官网三个按钮在每个气泡里都要滚动才看得到 | 动作行 `position:sticky`，内容在其下滚动。它仍在文档流里，所以不会盖住最后一行正文。上方用一道柔和投影而不是分隔线——它正上方的来源行自己已经有一条线，两条平行细线相距 20px 看起来像渲染故障 |
| **P1** 地区胶囊比地名还宽还要换行 | 胶囊只显示地名（`regShort`），括号里给新居民的解释移进 `title` |
| **P1** 一个气泡里六种胶囊、五种字号、三种圆角 | 收敛为三类：`pchip-id`（身份）/ `pv-open`（状态，唯一允许语义色）/ `pchip-meta`（其余）。同字号、同圆角、同最小高度 21px |
| **P1** 51 个饱和分类色以实心块出现在地名下 | 改为自身颜色的 11% 浅底 + 该色文字，并前置与地图针相同的分类字形。文字色由 `catInk()` 逐级加深直到对比度 ≥ 4.5:1 —— 51 个分类全部通过 |
| **P2** 分类胶囊是唯一"只有颜色没有图标"的标识 | 同上；分类筛选面板本来就直接打印 `IC[k]`，三处终于一致 |
| **P2** 电话 / 营业时间没有对齐轴，时间换行后取值跑到标签底下 | 三行并入一个 `.pkv` 两列网格，测试断言三个取值的左边缘完全相同 |
| **P2** 五段信息只靠 margin 区分 | 来源行上方加一条发丝线，动作行上方是投影，全气泡两处分区 |
| **P2** 最不重要的一行视觉最复杂 | 来源徽章的底色去掉，改为 6px 小圆点；四种来源仍由圆点颜色区分（测试断言四色互不相同） |
| **P3** 任务卡插在地址与电话之间，两个实心蓝按钮互抢 | 任务卡移到营业时间之后；它的按钮改为次级样式，气泡里唯一的实心蓝是"导航前往" |
| 收藏星是唯一的文本字形 | 改用图标集的星，选中时同一路径填充 |

## p28 设计令牌

- **字号** 19 个值 → 7 级：10 / 11.5 / 12.5 / 14 / 17 / 22 / 26。刻度特意保留了使用最多的三档（11.5、12.5、14），因此绝大多数声明只移动 0.5px，最大单次移动 1.5px 且方向向下。
- **圆角** 15 个值 → 4 个：6（行内徽章、输入框、细条、地图 tooltip）/ 10（小控件）/ 14（卡片、面板、抽屉、地图本体）/ 999（胶囊）。原先的 18 / 20 / 99px 都已经在胶囊形状的控件上，视觉等价，改成 999 是把意图写明。
  - 审视里说"收到 3 个"，实际落到 4 个：把小控件那一档并进卡片档，会让 24px 的关闭按钮带上 14px 圆角。
- **状态色** "已关门"原本是两个硬编码的 Material 灰，现在用页面自己的 `--paper` / `--sub-ink`；"营业中"和"节假日"改到 Apple 绿 / 橙家族。三对颜色的对比度 5.55 : 1、4.54 : 1、6.22 : 1。
- 未动：离线提示条与页脚紧急电话条的琥珀与红色。它们是页面级警示而非胶囊，颜色本身就是信号，且本来就达标。

## p29 地图针

水滴 → 扁平圆形，与聚合泡同一套零件：30px 圆、2.5px 白环、聚合泡自己的那组阴影，分类色在外、字形在内侧白面上（彩色 emoji 在 51 种底色上都要保持可读）。

两个附带影响写在这里：

- **锚点由水滴尖端移到圆心**。这与聚合泡一致，也与"坐标"本身的含义一致——地点从此落在自己的坐标上，而不是其上方 21px。
- 线路聚焦时原本靠去掉 SVG 滤镜来压暗，圆形带的是 `box-shadow`，所以那条规则改为作用在元素上，并从圆心而非已消失的尖端缩放。

### 改了三条既有断言（都是行为按设计变了，不是把测试改松）

- `tests/regress.py` 第 10 轮：收藏状态原先读 `.fav-star` 的 `textContent === '★'`，现在读 `aria-pressed`、`.active` 和是否渲染了 svg，并额外断言里面不再有 ★/☆ 字符。
- `tests/phase4test.py`：推荐标签的类名由 `tag-pick` 改为 `pchip-pick`，并断言名称区不再出现 ⭐。
- `tests/phase13test.py`："现在营业"那条原先要求结果数大于 0，凌晨没有任何药房营业时会误报。现在断言的是"筛选前有匹配、筛选后的数量与实际营业数一致"。

### 有意没做

- `.tag` / 公交线路气泡：那里实心线路色加白字是对的，保留。
- 51 个分类的线条图标：按你的选择保留 emoji，地图针、分类胶囊、分类筛选三处用的是同一个字形。
