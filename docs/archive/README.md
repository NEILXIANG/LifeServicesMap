这里放的是**某一时点的分析、决策过程和一次性操作手册**。它们记录了项目是怎么走到今天的，
但**不描述当前状态**，读它们之前请先看根目录的 `README.md` 和 `DATA-SCHEMA.md`。

归档于 2026-09-07。文件名统一加了日期前缀，原因见下。

## 为什么改了文件名

原来根目录和 `Claude outputs/` 里各有一套「UX审计三 / 四 / 五」，**编号相同但内容完全不同**，
说「第四轮审计」会有歧义。现在一律用 `日期-主题` 命名，能确定审查对象版本的在名字里标了
`对象vX.Y.Z`。
