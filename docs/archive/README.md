## 规则

- **只读，不改正文**。要更正当前做法，改现行文档；要补历史，在本 README 里加一行说明。
- **归档时不改文件名**：`docs/reports/2026-10-03-Kamloops经验总结.md` 用 R0910、CA 这类缩写引用这些文件，名字变了就对不上。
- 名字里能看出状态的就写上（`已废弃`、`已实施`、`已决策`、`对象vX.Y`）；看不出的写在下面的表里。
- 有价值的结论在归档前已经搬进现行文档（见"内容去了哪里"），这里只是证据。
