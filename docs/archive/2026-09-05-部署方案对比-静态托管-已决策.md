# Kamloops 生活服务地图 · 部署方案对比

> 目标：让使用人扫描**二维码**或直接打开 **URL**，**手机和电脑都能访问**。
> 文件特点：单 HTML，658KB，**零外部依赖**（Leaflet 已内嵌，只有地图底图要联网），所以**任意静态网站托管**都跑得起来。

---

## 30 秒结论

| 方案 | 步骤难度 | 国内访问 | 全球访问 | 二维码友好 | 免费 | 备注 |
|---|---|---|---|---|---|---|
| **A. Cloudflare Pages（直接拖拽）** | ⭐ 最简 | ✅ 尚可（比 GitHub Pages 好很多） | ✅ 极快 | ✅ 自动 HTTPS 自动短链 | ✅ 永久免费 | **首推**——一个浏览器标签页，30 秒部署完 |
| B. GitHub Pages | ⭐⭐ 需 git | ⚠️ 慢、不稳、常被劫持 | ✅ 稳 | ✅ | ✅ | 海外用户为主时选；国内不推荐 |
| C. 腾讯云 COS / 阿里云 OSS 静态网站 | ⭐⭐⭐ 需实名 | ✅✅ **国内最快** | ⚠️ 国内 CDN 不出国 | ✅ | ✅ 少量额度免费 | 面向国内用户时选，但需要实名 + 自有域名 |
| D. Surge.sh | ⭐ 命令行一行 | ⚠️ 不稳定 | ✅ | ✅ | ✅ | 老牌 CLI 部署，国内访问不稳 |
| E. Vercel / Netlify | ⭐ 简单 | ⚠️ 中等 | ✅ | ✅ | ✅ | 类似 Cloudflare，但 Cloudflare 更稳 |

**如果不知道选哪个**：选 **A（Cloudflare Pages 直接拖拽）**——下面给了 30 秒上手步骤。

---

## 方案 A：Cloudflare Pages（推荐，3 步）

不需要 git，不需要命令行。**一个浏览器标签就能部署**。

### 第 1 步：建仓库（30 秒）
- 浏览器打开 https://dash.cloudflare.com/
- 登录/注册（GitHub 账号一键登录）
- 左侧栏点 **Workers & Pages → Create → Pages → Direct Upload → Upload assets**
- 项目名随便起，比如 `kamloops-map`（这会决定你的二级域名 `kamloops-map.pages.dev`）

### 第 2 步：拖上去（10 秒）
- 把 `Kamloops生活服务地图.html` **改名成 `index.html`**（不改的话部署后访问需要带文件名）
- 把改好名的文件拖进上传框
- 点 **Deploy site**

### 第 3 步：拿到 URL + 做二维码（10 秒）
- 部署完后，地址栏给你一个 `https://kamloops-map.pages.dev`
- 把它复制出来，在 https://www.qrcode-monkey.com/ 粘进去 → 下载 PNG/打印
- 二维码图片发给朋友，或印个 A4 张贴到社区公告栏

### 想用自己域名？
- Cloudflare 里把 `kamloops-map.pages.dev` 改成 `map.yourdomain.com`，照着引导配 DNS，**全程不收费**、自动 HTTPS。

## 方案 B：GitHub Pages（如果你已经在用 GitHub）

适合已经用 git 管理这个项目的人。

```bash
cd "/Users/neilxiang/Documents/me/canada/Guide to Life in Canada"
# 把 HTML 改名（仅用于 GitHub Pages 部署，原文件请保留）
cp Kamloops生活服务地图.html index.html

# 提交并推到远端仓库的 main 分支
git add index.html
git commit -m "deploy to pages"
git push

# 然后在 GitHub 网页：Repo → Settings → Pages → Source: main → Save
# 你的地址是 https://<用户名>.github.io/<仓库名>/
```

⚠️ 国内访问慢是 GitHub Pages 的硬伤——不是项目本身的问题，是国内到 GitHub 的网络问题。

---

## 方案 C：腾讯云 COS 静态网站（国内访问最快）

需要实名（一个工作日通过）+ 一个已备案域名。
操作不复杂，但比方案 A 多 3-4 步。

- 腾讯云控制台 → 对象存储 COS → 创建存储桶 → 开启**静态网站托管**
- 把文件改名 `index.html` 上传（首字节 0 延迟）
- 绑定自定义域名 → 自动配 SSL → 拿到 `https://map.example.com`

境内 CDN 节点拉满，打开速度比方案 A 还快一档，但**完全不考虑海外**。

## 部署后的二维码

任选一种：

**网页版**（最简单）：
1. 打开 https://www.qrcode-monkey.com/ 或 https://cli.im/url
2. 粘贴你的 URL
3. 下载 PNG

**命令行**（顺手做）：
```bash
brew install qrencode           # macOS 安装一次
qrencode -o kamloops-qr.png "https://kamloops-map.pages.dev"
open kamloops-qr.png
```

**手机端**（拍照到屏幕）：
- 系统相机对准 URL 显示的二维码即可识别
- 或者微信 → 扫一扫 → 相册 → 选二维码图片

## 推荐路径总结

| 你的主要使用人群在… | 选方案 |
|---|---|
| 加拿大本地华人 | **A. Cloudflare Pages**（首选） |
| 中国境内的新移民/家属 | **C. 腾讯云 COS** + 自有已备案域名 |
| 全球混合用 | **A. Cloudflare Pages**（兼顾） |
| 项目本来就在 GitHub 上 | **B. GitHub Pages**（最省事但国内慢） |

不论选哪条，最终发布物**都是同一个 `index.html`**，658KB、零依赖、可离线（除底图）、支持手机+电脑浏览器。
