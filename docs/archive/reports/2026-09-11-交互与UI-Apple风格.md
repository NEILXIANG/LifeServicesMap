# 交互逻辑：按 Apple 风格的检查与改动（v2026.09.11a）

日期：2026-09-11 · 依据：Apple Human Interface Guidelines 里对交互的几条硬要求——**清晰**（一眼知道能做什么）、**退让**（界面让位于内容）、**直接操作**（手指拖的东西跟着手指走）、**一致的退出**（任何一层都能用同一种方式离开）、**宽容**（做错了能撤销，不用先确认）、**导航栈**（Back 回上一层，而不是退出）。

## 一、逐项检查

| 交互 | 检查前 | Apple 的做法 | 现在 |
|---|---|---|---|
| 筛选面板（区域/分类/公交/收藏） | 已是底部抽屉：有把手、可下滑关闭、点外面关闭 | 同 | 不变；加了系统 Back 关闭 |
| **指南、数据说明、分享** | 手机上是**居中弹窗**——桌面的习惯用在手机上；无把手、不能下滑 | 从底部升起的 sheet，有把手，下滑即关 | 手机（≤900px）改为 sheet：上圆角、把手、升起动画、从把手或标题栏下滑超过三分之一或快速一甩即关；桌面保持居中对话框 |
| **系统 Back 手势** | 任何弹层打开时按 Back → **直接离开网站** | Back 关掉当前一层 | 打开任何 sheet 推入一条历史；Back 关 sheet；用 ✕/Escape/点外面/下滑关掉的，会自己把那条历史消掉——Back 永远不会退到一个"应该已经关了的 sheet" |
| **指南内的导航栈** | 打开一张卡后按 Back → 整个指南关掉 | 卡 → 列表 → 关闭，一层一层 | 卡片是列表的下一层：Back 回列表，再 Back 才关指南；卡里的"← 返回全部事项"与 Back 等价；从卡里直接 ✕ 关闭会一次消掉两层历史 |
| **宽容（Undo）** | Reset 和"清除全部"立刻生效，无法反悔 | 不弹确认框，事后可撤销 | 两者都出一条 5 秒的提示"已恢复全市视图 · 撤销"，撤销恢复到之前的区域/分类/主题/预设/现在营业/搜索词/线路/地图视角 |
| **选中态的一致性** | 快捷芯片选中是**鼠尾草绿实心**，同一个筛选在筛选条里是**浅蓝**——同一个状态两种颜色 | 一个强调色贯穿所有"已选" | 快捷芯片选中改为浅蓝底、蓝字、蓝边，与筛选条芯片同款；页面上唯一的实心蓝仍是指南入口 |
| **按压反馈** | 按钮按下无变化 | 按下略微缩小 | 芯片、筛选按钮、卡片、列表项、操作按钮按下缩放 97%，`prefers-reduced-motion` 下自动取消动画 |
| 提示（toast） | 底部居中，1.6 秒 | 同；有操作按钮时停留更久 | 带"撤销"时停 5 秒，按钮可点 |
| 退出方式 | ✕、Escape、点外面 | 加上 Back 与下滑 | 现在五种方式对每一层都成立 |
| 搜索框 | 输入即出 ✕ | 同 | 不变 |
| 语言切换 | 分段控件式 | 同 | 不变 |

## 二、明确没做的两件"最 Apple"的事，以及原因

1. **底部标签栏**（指南 / 地图 / 收藏）。这是 iOS 应用最典型的导航。没做，因为它固定占掉 56px，手机上地图的屏幕占比会跌破回归设定的 40% 底线；做成悬浮覆盖在地图上又会盖住地图署名。这是一次需要重新校准全部手机布局基线的改动，单独排一轮。
2. **Apple Maps 式的地点卡**（点图钉后从底部升起的卡片，而不是锚在图钉上的气泡）。没做，因为回归里三十多项检查围绕气泡（高度、溢出、署名可见性、多语言）建立；换成底部卡片要同时重写这些检查。它是下一轮的候选，收益明确。

## 三、回归

新增的行为都进了本轮验证：sheet 的 Back 关闭、从卡里 Back 回列表、深链接进入卡后两次 Back 回到地图、下滑关闭、Undo 恢复到位、六语提示字串。全套 279 项零失败后提交。

## 四、UI 风格（同一轮）

Apple 系统调色：文字 #1c1c1e / 次级 #6e6e73（5.0:1）、分组背景 #f2f2f7、发丝分隔线 #d1d1d6、蓝色取 Apple 蓝系但压深到 #0b6be0（白字 5.0:1，AA）；语言切换改为灰轨道 + 白色选中胶囊；芯片与分类按钮改为胶囊；地图容器 16px 圆角；浮动条（线路指示、首次卡）改为半透明白 + 背景模糊；所有阴影换成一族柔和阴影；弹层背景轻微模糊（桌面的筛选弹窗不模糊页面——它旁边就是要看的地图和计数）。

## 五、复扫（对本轮改动的独立检查）与修正

独立扫描在新构建上抓到三处由本轮引入的 P0，均已修：
1. 在面板里改的筛选/线路，关面板时会从地址栏消失（我们自己 `history.go(-1)` 时浏览器恢复了旧 URL）→ 弹出后重写 URL。
2. 线路模式下 Reset 再撤销，会留下二百多个不该显示的图钉/聚合泡（`hideMarker` 只从当前图层移除）→ 从两个图层都移除。
3. 桌面版分享对话框可以点穿、点外面关不掉（`#shareBackdrop` 漏在 pointer-events 规则外）→ 补上。

P1：刷新时若有弹层打开、再点 ✕ 会整页导航 → 加载时清掉历史标记；桌面筛选弹窗模糊了整页 → 只在有遮罩的弹层上模糊；筛选条 ✕ 只有 15px、分组勾选框 16px、展开按钮 14px 高 → 触屏 36px；名字里的编辑推荐 ⭐ 与收藏 ☆ 撞车 → 弹窗标题去掉 ⭐，改为"⭐ 推荐"标签；对比度：语言按钮 4.18、页脚隐私行 3.04、地标副行 3.75、完成徽章 4.27、搜索 ✕ 3.29 → 全部提到 4.5 以上；灰搜索框在灰页面上分不清 → 白底发丝边。P2：状态行"线路"排到区域之前不再被截；提示条避开 Home 指示条；快捷芯片补 `aria-pressed`；地图搜索交接补"孩子上学""school registration""怎么办医保卡""cómo obtengo la tarjeta de salud"。

首次卡加一行"免费 · 不用注册 · 不收集你的任何信息"（安全感在第一秒）。

## 六、仍然严重、这轮没解决的（诚实清单）

1. **单文件 1.39 MB（gzip 505 KB）**：4× CPU 节流的手机上首个图钉 2.2 秒。真正的 3G 用户会等 5 秒以上。解法是按区懒加载地点数据，一次架构改动。
2. **25 条 `precision:'low'` 的坐标**（其中 9 条是本周内插的）：图钉可能偏 100–300 m。导航用的是地址不是坐标，所以"导航"是对的，"在地图上找"可能不对。需要有人在真机地图上逐一落点。
3. **`/api/event` 对任何来源开放（CORS *）且无速率限制**：任何人能往统计里灌假数据或耗光 Analytics Engine 配额。至少加 Origin 校验和每 IP 限速。
4. **HTML 响应无安全头**（CSP、Referrer-Policy、X-Content-Type-Options）：单文件内联脚本使 CSP 需要 nonce/hash，非一行能加，但缺了它任何 XSS（比如数据文件被污染）都无护栏。
5. **手机上地图从 372–421px 处才开始**（en/fr/es/ja）：首屏一半是导航。指南优先的定位下这不算错，但一个只想看地图的老居民要滚一屏。
6. **只有一家真正的 walk-in 诊所**（North Shore UPCC）——这是城市的事实不是数据的错，但"生病"卡应更醒目地说"别去别处白跑"。
7. **`?task=` 深链接需要按三次 Back 才能离开网站**：卡 → 列表 → 关 → 离开，逻辑一致但对从传单扫码进来的人偏多；可考虑深链接进入时只推一层。
