# UI 美学审视：地图气泡与整体风格（2026-09-24）

> 只做分析与建议，**本次不修改任何代码**。证据来自 430px 手机视口的实机截图、`src/engine.html` 的 CSS 与 `popup()` 渲染函数。

---

## 一、结论先说

整体风格是**有体系的**：Apple 系统调色（`#1C1C1E` / `#6E6E73` / `#F2F2F7` / `#D1D1D6`、单一蓝 `#0B6BE0`）、系统字体栈、999px 胶囊控件、白卡 + 柔和阴影。头部、搜索、筛选按钮、Quick Pick 这一段做得很干净，是产品最好看的部分。

问题不在"不好看"，而在**页面上同时跑着三套互不相干的视觉语言**：

1. Apple 灰蓝体系（外壳）
2. 51 种分类色 + 彩色 emoji（地图与气泡）
3. Material 风格的状态柔和色（`#e6f4ea` 绿 / `#fff3d6` 琥珀 / `#fde8e6` 红）

越往气泡里看，第 2、3 套越占上风，外壳的克制就被冲掉了。这是"可优化空间"的主线。

---

## 二、气泡（弹窗）——按严重度排序

### P0｜主操作按钮永远在折叠线以下
三个动作按钮（导航前往 / 电话 / 官网）排在气泡最底部。实测：食物银行、Dallas 小学、托儿所三个气泡，在 430×930 手机上**全部需要滚动才能看到导航按钮**，"最近的公交站"那一行就已经被裁断了。气泡最重要的转化动作，默认不可见。

- 方向：动作行固定在气泡底部（sticky），或上移到地址行正下方；内容区滚动，动作区不滚动。
- 附带：现在滚动区没有任何"下面还有"的提示，底部加一层渐隐（mask）即可。

### P1｜地区胶囊喧宾夺主
`Sahali/Aberdeen (hillside south of Downtown, home to TRU)` 是一个深灰实心胶囊，宽度**超过地名本身**，还要换行。括号里的解释是给新居民的好设计，但它不该以"胶囊"这种最重的容器出现在第二行。

- 方向：地区降为一行浅灰小字，或保留胶囊但把括号解释移到 `title` / 点击展开。

### P1｜一个气泡里有 6 种胶囊语言
同一屏里并存：分类实心色块（5px 内的圆角）、地区实心灰胶囊、`tag3` 描边胶囊、主题胶囊（浅灰 + 线性图标）、来源徽章（5px 圆角、绿底绿字）、营业状态胶囊（999px、灰底）。字号 9.5 / 10.5 / 11 / 11.5 / 12.5 各不相同，圆角 5 / 14 / 999 混用。

- 方向：收敛成 **3 类** —— ①身份（分类，带图标，浅色 tint）②状态（营业中 / 今日节假日，唯一允许用语义色）③元信息（地区、来源、主题，统一浅灰描边）。同类同字号、同圆角、同高度。

### P1｜分类色是第二套配色系统
`CD` 里 51 个手挑的深色（`#ad1457` 洋红、`#b3552f` 砖红、`#8a5a9e` 紫…），以实心大色块出现在地名正下方。在一个"只有一个蓝色重音"的克制界面里，这等于每打开一个气泡就换一次品牌色。

- 方向：气泡里的分类胶囊改成**同色系浅底 + 深字**（tint），把饱和色只留给地图针（那里需要辨识度）；再把 51 色归并到 8–10 个语义族（医疗 / 教育 / 食物 / 交通 / 政务 / 休闲 / 商业 / 社区），族内用明度区分。

### P2｜分类胶囊没有图标，是唯一"只有颜色"的身份标识
主题胶囊有线性图标、地图针有图标、筛选面板有图标，唯独气泡里的分类是纯文字色块。读者因此无法把"这个气泡"和"地图上那个针"、"筛选里那一项"连起来。

- 方向：分类胶囊前置该分类的线性图标（`IC` 已有映射，走 `emojiIcon()` 即可），三处视觉一致。

### P2｜标签/取值没有对齐轴
`电话 250-…`、`营业时间 [状态] Mon–Sat 8 AM–…` 是行内标签，营业时间换行后取值直接跑到标签下面。气泡缺一根竖向的"脊椎"。

- 方向：两列网格（标签 48–56px 固定 + 取值 1fr），标签统一 `--sub-ink`，取值统一 `--ink`。

### P2｜信息分区没有分隔
身份 → 事实 → 说明 → 元信息 → 动作，五段只靠 margin 区分，密度均匀，所以没有主次。而应用的其它面板是用发丝线分区的。

- 方向：元信息行上方、动作行上方各一条 `--line` 发丝线，共两条，足够。

### P2｜最不重要的一行，视觉最复杂
`Source: Official site · Verified September 2026 · Report an issue` —— 绿底徽章 + 灰字 + 蓝链接，三种处理挤在 10.5px 一行。它是可信度的证据，但不该比地名更花。

- 方向：整行降为灰色小字，来源用一个小圆点 + 文字，"报告问题"放行尾并去掉链接蓝（hover 才出下划线）。

### P3｜任务卡插在地址和电话之间
"Doing something here? See the steps" 是气泡里唯一的蓝底块，做得好，但它把电话/时间这些核心事实往下推了约 90px，而它自己的蓝色按钮又和（看不见的）主 CTA 抢焦点。

- 方向：移到营业时间之后、备注之前；或按钮改为次级样式（蓝字白底），把实心蓝只留给"导航前往"。

## 三、图标（承接 p26 的检查）

p26 已修掉语义错的和老机型渲染不出的那几个。剩下的是**风格一致性**，不是对错：

| 位置 | 现状 | 问题 |
|---|---|---|
| 收藏星 ☆ / ★ | 文本字符 | 细瘦、琥珀色、和旁边所有 1.8px 线性图标不是一套 |
| 备注开头的 ⭐ | 彩色 emoji | 夹在灰色正文里，唯一的彩色字符 |
| 地图针内的图标 | 彩色 emoji | 针是拟物水滴 + 彩色 emoji，聚合泡是扁平几何圆 + 数字 —— 同一张地图两种语言 |
| 地点标签（"North Kamloops Library"） | 白底蓝粗体方块 | 读起来像按钮，和针抢注意力 |

- 方向：收藏星和备注 ⭐ 换成线性图标；地图针改为"彩色圆底 + 白色线性图标"，与聚合泡的扁平语言统一（这是改动最大、收益也最大的一项，需要单独排期和回归）。
- 保留不动：`🪶` 原住民服务（无替代）、`⚠️` toast、`📲` 分享（周围都是渠道 logo）。

## 四、整体美学：可量化的松散处

| 维度 | 现状 | 建议 |
|---|---|---|
| 字号 | **19 个**不同 px 值（9 / 9.5 / 10 / 10.5 / 11 / 11.5 / 12 / 12.5 / 13 / 13.5 / 14 / 14.5 / 15 / 15.5 / 16 / 17 / 18 / 22 / 26） | 收到 6 级（11 / 12.5 / 14 / 17 / 22 / 26），层级改用**字重和颜色**表达，而不是 0.5px 的差 |
| 圆角 | **15 个**不同值（3–999px） | 收到 3 个：6px（徽章）、14px（卡片/气泡）、999px（胶囊） |
| 颜色 | Apple 灰蓝 + 51 分类色 + Material 柔和状态色 | 状态色换成 Apple 语义色（绿 `#34C759` 系、橙 `#FF9500` 系）的浅底版本，和外壳同源 |
| 密度 | 全局一致的中等紧凑，没有呼吸 | 首屏只给一处大留白（地名区），其余维持 |
| 深色模式 | 已于 2026-09-07 主动移除（瓦片是亮色，只改外壳会更糟），`color-scheme:light` | 这个决定是对的。若将来要做，必须连瓦片图层一起换，属于独立项目 |
| 首屏配比 | 标题 + 两行副标题 + 搜索 + 4 筛选 + 计数 + Quick Pick + 提示行 = 约 55%，地图只剩 45% 且底部被 Leaflet 版权条压住 | 副标题在第二次访问后收起；地图上移，版权条改为角标；地图是产品的主角，应该拿到首屏一半以上 |

---

## 五、如果只做三件事

1. **动作行固定在气泡底部**（功能性问题，影响每一次使用）。
2. **统一胶囊系统 + 分类色改 tint**（一次改完，气泡立刻"归队"到 Apple 体系）。
3. **地图针改为扁平圆底 + 线性图标**（收尾整个图标迁移，地图和 UI 终于一套语言）。

第 1 项风险最低，第 3 项收益最大但需要完整回归。
