# Kamloops Newcomer Assistant：给机构的说明

**测试版，2026 年 10 月** · https://kamloops-assistant.neilxiang.workers.dev · 编写：Neil Xiang

## 这是什么

一个免费网页。新移民本人，或者帮助新移民的工作人员，可以用任何语言问日常安顿的问题，比如孩子入学、MSP、SIN、食物、法律援助。回答由 AI 撰写，但**只根据 Kamloops 生活指南里已核实的内容**（17 张分步骤的办事卡、387 个地点），每一步都写明来源和最后核实的月份。

这是一个**独立的试点**，不是 Kamloops Immigrant Services、Kamloops 市政府或任何政府部门的服务，每个页面上都写明了这一点。生活指南本身不变，和助手是分开的：指南仍然免费、可以离线使用、不收集任何个人信息。

## 回答是怎么产生的

1. **先做危机检查。** 如果问题像是涉及暴力、自伤或其他紧急情况，包括替别人问的情况，页面会立刻显示 9-1-1 和 24 小时求助热线。**这个问题不会发给 AI。**
2. **查指南。** 程序从指南里挑出相关的办事卡和地点。
3. **写回答。** Anthropic 的 Claude 模型只根据这些内容写一个简短的回答，每一步都标明来源。
4. **核对回答。** 显示之前，程序检查：每个引用的来源都确实存在；每个电话号码和网址都出现在它引用的来源里。没通过检查的步骤会被删掉；如果全部删光，页面会说明指南里没有已核实的信息，并转介 KIS 和 2-1-1。

## 它不会做的事

- 对任何人的资格、移民身份、法律处境或医疗情况下结论。遇到这类问题，它只给出一般流程，并告诉对方个人情况可以找谁。
- 编造电话号码、地址、费用或期限。
- 执行问题里夹带的指令（比如"忽略你的规则"）。
- 取代定居服务专员。它会把人引导到定居服务专员那里。

## 隐私

| | |
|---|---|
| **不收集** | 姓名、联系方式、证件号码、移民身份、健康信息。页面会提醒用户不要输入；如果问题里像是有电话、邮箱或证件号码，发送前还会再提示一次。 |
| **不保存** | 提问和回答不保存在任何地方，服务器日志也不记录提问内容。 |
| **发给 AI 服务的内容** | 只有提问的文字和相关的指南内容。服务是 Anthropic 的 Claude API；Anthropic 是美国公司，所以问题会在加拿大境外处理。Anthropic 默认不用 API 数据训练模型。危机类问题从不发送。 |
| **使用次数** | 为了统计每天的提问次数，只保存用访客网络地址和日期生成的单向编码（不保存地址本身），两天后删除。 |
| **反馈** | 匿名的"有用 / 有错 / 没回答我的问题"，可以附一句说明（数字和邮箱会被去掉）。 |

如果机构打算向客户推荐它，可能需要先做自己的隐私审查。在 BC 省，做隐私影响评估（PIA）是常见做法。

## 费用和限制

- 每个回答约 **4 美分（美元）**。目前由 Neil 承担，从预充值的 Anthropic API 账户里扣，花费不会超过已充值的金额。
- **测试版的限制：** 每人每天 10 题，每分钟最多 5 题，全站每天 200 题。危机类问题不计次数。
- 机构和用户都不需要付费。

## 做过哪些测试

- 每次发布前运行 74 项自动检查。这些检查用模拟的 AI，故意制造编造的电话、假的来源、六种语言的危机说法（第一人称和第三人称）、夹带的指令和翻译错误，证明每一道保护都能拦住。
- 准备了 30 道测试题，覆盖常见流程、个人资格、危机、指南答不了的问题、诱导编造号码、夹带个人信息、其他语言。每次改动后，用真实的 AI 重跑其中的核心几题（日常流程、个人资格、夹带指令）；危机题每次都检查，而且不经过 AI。
- 在手机和电脑的浏览器里，用全部六种界面语言人工检查过，包括深色模式。

## 语言

界面有英文、法文、西班牙文、中文、韩文和日文。可以用任何语言提问，回答会用提问的语言。

## 可控性

- 随时可以改成**只有工作人员可用**（用登记的邮箱登录），或者**直接关闭**，都不影响生活指南。
- 指南内容更新并重新核实后，助手在下一次重新构建时就会用上新内容。

## 希望得到你们的帮助

1. 试问 3 到 5 个工作人员最常被问到的问题，告诉我们哪些回答有错、说不清楚或者缺内容。
2. 告诉我们它对工作人员更有用、对客户更有用，还是都没什么用。
3. 告诉我们，要让你们放心把人引导过去，还需要什么，比如隐私、措辞或监督方面的要求。
