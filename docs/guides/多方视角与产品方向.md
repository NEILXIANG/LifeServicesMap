# 多方视角：每一方希望这个工具是什么样子

> 2026-10-03 初稿，做 Kelowna 时持续迭代。新移民本人的视角见 `docs/guides/新移民画像与需求.md`；
> 这里补上另外三方——政府机构、移民服务中心、公益组织——以及它们之间的关系。
> 结论只是假设：**每一条都要拿去问真实的机构**（第六节），问完回来改这份文档。

---

## 一、新移民（使用者）

**想要**：一个打开就能用、说我的语言、告诉我"下一步做什么、去哪里、带什么"的工具；信息可信；不用注册；没网也能用。
**怕**：信息过时害我白跑一趟；被记录、被追踪；看不懂；被骗。
**会因为什么推荐给别人**：它真的帮我办成了一件事，而且朋友能用他们的语言打开。

## 二、政府机构（市政府、省政府、健康局、应急管理、联邦部门）

**它们的目标**
- 居民能找到并正确使用公共服务：轻症去 UPCC 或打 8-1-1，而不是挤急诊；灾害时人人收到警报。
- "欢迎型社区"：新移民留下来、融入、就业（本地移民伙伴关系 LIP 的目标）。
- 公平：语言、身份、收入不同的人都能得到同样的信息。

**它们希望这个工具**
- **和官方信息一致**，每条都链接回官方来源，绝不说出与官网矛盾的话。
- **更新及时**：规定一变（费用、办事处搬家、警报系统更换——Kelowna 2026 年 4 月换成了 Alertable），工具跟着变。
- **符合公共标准**：无障碍（WCAG）、隐私（不收集个人信息）、尊重原住民（称谓和土地致谢经当地 Nation 确认）、包含法语。
- **能告诉它们"缺什么"**：匿名、汇总的需求信号——大家最常搜什么、搜不到什么、哪些语言用得最多。这对规划服务很有价值。

**它们的顾虑**：责任（工具说错话，居民怪政府）；与官方渠道重复或冲突；第三方商业动机（广告、卖数据）。

**它们可能贡献**：开放数据（已经在用）、在官网或欢迎资料里放链接、核实各自的条目。

## 三、移民服务中心（Kelowna：KCR；还有 SD23 欢迎中心的 SWIS）

**它们的现实**
- 前线人手紧，每天回答大量重复的基础问题（SIN 在哪办、MSP 怎么申请、哪路车去哪儿）。
- 客户语言多样，口头说过的转介地址客户转身就忘。
- 服务资格按身份不同，常有不符合条件的人来问。
- 需要证明成效（资助方要看服务数字）。

**它们希望这个工具**
- **是它们的帮手，不是替代**：基础问题由工具回答，复杂个案引导到它们那里；工具里"去找安置机构"的路径要清楚。
- **能在前线直接用**：和客户坐在一起时，切换到客户的语言，把一张办事卡或一个地点**发到客户手机上**或**打印一页**。
- **转介清单永远是最新的**：它们自己维护的转介表很快过时，希望有一个共享的、可信的版本。
- **写清楚资格**：哪些服务谁能用，减少白跑。
- **它们自己的信息由它们说了算**：项目、时间、语言、联系方式能方便地更新。

**它们的顾虑**：工具给出错误的移民或法律建议；客户绕过它们；被看作背书一个它们不能控制的产品。

**它们可能贡献**：核实条目、在接待时推荐、提供"最常被问的问题"、把工具放进欢迎资料包（这正是 Kamloops 最缺的分发渠道）。

## 四、公益组织（食物银行、庇护所、法律诊所、心理健康机构、宗教和社区团体）

**它们希望这个工具**
- **对的人找到它们**：写清楚服务对象和条件，避免不符合条件的人来、需要的人不知道。
- **时间准确**：过时的开门时间会让饿着肚子的人白跑，也让前台受气。
- **保护敏感信息**：庇护所地址保密，只给电话（Kelowna 女性庇护所已经这样处理）。
- **更新简单**：没有专人维护网站，希望一封邮件或一个表单就能改。
- **也能招志愿者、接受捐助**（次要，但对它们重要）。

**它们的顾虑**：被不准确地描述；被推上它们接不住的需求量。

## 五、综合：四方都同意的东西 → 产品方向

| 共识 | 产品上怎么做 | 现状 | 优先级 |
|---|---|---|---|
| **准确、可溯源** | 每条记录有官方来源、核实日期；不确定就说不确定 | 已有来源分级和核实日期 | 保持 |
| **机构自己的信息由机构确认** | "机构确认"标记：机构核实过的条目显示"由本机构于某月确认"；提供一张简单的更新表单（或邮件），每季度提醒一次 | 没有 | **高**——这是信任和维护成本的关键 |
| **写清楚谁能用** | 服务对象：永久居民 / 临时居民 / 学生 / 难民 / 所有人；先写在备注里，第二次遇到就加正式字段（方法论第七节） | 没有 | **高** |
| **前线可用** | "发给客户"：一张卡或一个地点生成短链接和二维码，用客户的语言打开；打印友好的一页 | 有分享和打印，但不是为前线设计的 | 中 |
| **转介到人，而不是替代人** | 每张办事卡底部："需要人帮忙？"→ 安置机构 / 学区欢迎中心，带电话和资格说明 | 部分有 | 高 |
| **安全与敏感信息** | 危机词搜索、24 小时热线；庇护所只给电话 | 已有 | 保持 |
| **需求信号回馈给机构** | 每季度一份匿名汇总报告给合作机构：热门搜索、搜不到的词、语言分布、热门办事卡（不含任何个人信息） | 有统计，没有对外报告 | 中——也是合作的交换条件 |
| **无广告、无数据买卖、开放** | 写进关于页面；开放数据子集可下载（已有 `export-open.py`） | 部分 | 保持 |
| **尊重原住民** | 原住民内容请当地 Nation 审阅 | Kelowna 待做 | 上线前必须 |
| **无障碍和法语** | WCAG 检查；法语是六种语言之一 | 有法语；无障碍做过审查 | 保持 |

## 六、怎么验证（下一步要问的问题）

| 对象 | 要问的问题 |
|---|---|
| KCR 移民服务 | 你们最常被问的 10 个问题？转介最多的 10 个地方？如果有一个工具能把办事卡用客户的语言发到客户手机上，你们会用吗？你们愿意每季度确认一次自己的条目吗？ |
| SD23 欢迎中心 / SWIS | 新来的家庭在入学前后最常卡在哪里？学区划分和法语课程的说明够不够清楚？ |
| UBCO 国际学生办公室 | 学生落地头两周最常问什么？住房和交通的问题有多大？ |
| 市政府 / 本地移民伙伴关系 | 你们希望看到哪些匿名需求数据？可以在官方欢迎资料里放链接吗？ |
| 食物银行、法律诊所、CMHA | 你们的服务对象和时间我们写得对吗？你们愿意怎样更新信息？ |
| 3–5 位新到居民 | （不讲解）用工具办一件事，卡在哪里？ |
