# 换位思考：新移民是谁、需要什么、难在哪里

> 2026-10-03 初稿。用途：作为开发、设计和数据准备的依据之一——每个功能、每类数据都应该能回答"这帮了哪一类人、在哪个阶段、解决了什么困难"。
> 依据：Kelowna/Kamloops 城市画像（统计局普查、IRCC、CMHC）、Kamloops 的访问记录与反馈、Kamloops 内容审查中发现的问题（`docs/reports/2026-10-03-Kamloops经验总结.md`）。
> 带"待核实"的是需要向安置机构或官方确认的判断。**这份文档要靠真人访谈来修正**：每座城市都应请安置机构、SWIS 工作人员和几位新到的居民看一遍。

---

## 一、他们是谁：七类人

| 人群 | 典型情况 | 最急的事 |
|---|---|---|
| **经济类永久居民（常带家庭）** | 技术移民、省提名；有学历但没有本地经验；带孩子 | 住房、工作、孩子入学、医保 |
| **国际学生** | 年轻、预算紧、第一次独立生活；有学校的国际学生办公室 | 住在哪、怎么上学（校园可能在城市边上）、打工规定、医保 |
| **临时外劳 / 季节农工** | 雇主安排住处、英语有限、常在城外的农场（果园、酒庄等）、工作时间长、怕得罪雇主 | 权利（工资、住宿、安全）、看病、汇款、手机 |
| **难民** | 政府或私人担保、经历创伤、可能英语很少、家庭大 | 一切从零：住房、语言、心理支持、孩子 |
| **家庭团聚（配偶、父母）** | 父母辈语言障碍最大，容易孤立；配偶可能在家照顾孩子 | 看病、交通、社交、语言课 |
| **英语国家来的移民（英、美）** | 语言没问题，但制度完全不同（医保、驾照、信用记录、报税） | 制度差异："在这里怎么办" |
| **外省迁来的加拿大人** | 不是移民，但对本地一无所知 | 本地信息：去哪儿办、哪路车 |

每座城市的规模（每年新永久居民、国际学生、季节外劳岗位、来源国、外省迁入比例）写在它的 `cities/<城市>/PROFILE.md`"对人群和需求的含义"一节。例如 Kelowna：见 `cities/kelowna/PROFILE.md`。

同一个人会同时属于几类（例如学生毕业后转工签、再转永久居民），需要的东西会随身份变化。

## 二、共同特征（设计时要假设这些都成立）

1. **时间紧、事情多**：落地后几周内要办 SIN、银行、手机、医保、住房、入学，很多事有先后顺序和期限。
2. **没有本地网络**：没有可以问的人，没有推荐人，没有本地信用记录和租房记录。
3. **语言能力不一**：从流利到几乎不会英语；就算会英语，也不熟悉制度用语（catchment、walk-in、MSP、SIN）。打电话比面对面更难。
4. **信息过多又不可靠**：微信群、Facebook 群、亲友经验里有大量过时或错误的信息；官方网站又分散、难懂。
5. **大多没有车**：至少头几个月靠公交和步行；城市的形状（狭长、跨河跨湖、桥少）决定通勤有多难，写进各城市的画像。
6. **手机是唯一的设备**：可能还没有本地电话卡和流量，常在图书馆或店里用 Wi-Fi；屏幕小。
7. **对政府和"被记录"可能有顾虑**：来自对官方有戒心的国家，或担心身份问题；不愿意注册、不愿意留下信息。
8. **钱紧**：头几个月只出不进，需要知道什么是免费的、什么有补贴。
9. **心理压力大**：孤独、想家、身份焦虑、职业落差，往往不会主动求助。
10. **不知道自己有什么权利**：租房、工作、歧视、医疗方面的权利，不知道去哪里申诉。

## 三、按时间看需要什么

| 阶段 | 需要 | 现在工具里对应的 | 每座城市要查清的本地答案 |
|---|---|---|---|
| **落地第一天** | 从机场到住处；吃饭；手机卡；安全 | 地图、公交线路 | 机场 / 车站到市区怎么走（用 GTFS 按星期几核实） |
| **第一周** | SIN、银行、手机、临时住处、安置机构 | 办事卡（SIN、银行）、安置机构地点 | 安置机构在哪、按身份谁能用 |
| **第一个月** | 医保（有等待期）、长期住房、孩子入学、语言课 | MSP 卡、学校、托儿（含工作人员会的语言） | 医保等待期内看病去哪；本地租房防骗渠道 |
| **前三个月** | 找工作、驾照换领、家庭医生登记、报税身份 | WorkBC、ICBC、办事卡 | 学历认证、找工作的本地资源 |
| **第一年** | 信用记录、融入社区、心理健康、法律权利 | 图书馆、社区中心、危机热线、法律援助 | 社交和志愿活动；本地的灾害类型与季节 |
| **随时** | 生病、紧急情况、被欺负或被骗 | 求助按钮、热线、危机词搜索、"现在营业" | 本地危机小组（有没有、谁运营、几点） |

每座城市在 `cities/<城市>/PROFILE.md` 的"对人群和需求的含义"一节写出这一列的本地答案和还缺什么。例如 Kelowna：见 `cities/kelowna/PROFILE.md`。

## 四、他们会遇到的困难（以及我们能做什么）

| 困难 | 具体表现 | 工具能做的 | 工具不能做、要转介的 |
|---|---|---|---|
| **鸡生蛋问题** | 没有 SIN 开不了某些账户、没有住址办不了手机、没有信用租不到房 | 办事卡写清楚先后顺序和"没有 X 时怎么办" | 个案帮助 → 安置机构 |
| **找不到家庭医生** | 只能去免预约诊所或急诊 | 列出 UPCC 和免预约诊所，"现在营业"，8-1-1 | 家庭医生登记（Health Connect Registry） |
| **住房贵、骗局多** | 房租高（各城市的数字见其 PROFILE.md）；先付押金后失联的骗局 | 租房办事卡：押金规则、看房要点、举报渠道 | 租房纠纷 → 住房仲裁处（RTB） |
| **交通** | 没车、跨河跨湖、到高校或机场要换车 | 公交线路、换乘站、地点旁的"怎么去" | — |
| **语言** | 电话听不懂、表格看不懂 | 六种语言；备注写"可要求免费翻译"；托儿所和机构标明会哪些语言 | 翻译服务 → 安置机构、8-1-1 的翻译 |
| **身份决定资格** | 很多免费服务只对特定身份开放（例如联邦资助的安置服务主要面向永久居民，省政府另有面向临时居民的服务——待核实） | 地点和办事卡标明"谁能用" | 资格判断 → 机构本身（工具不替人判断移民资格） |
| **被利用** | 外劳被扣工资、被要求交中介费；学生打工超时 | 权利办事卡；举报渠道 | 法律援助、劳工标准处 |
| **孤立与心理** | 父母辈、在家带孩子的配偶、难民 | 社区中心、图书馆活动、宗教场所、心理热线 | 心理咨询 → 专业机构 |
| **灾害** | 山火疏散、烟雾、洪水，不知道去哪里看通知 | 季节提示 + 紧急警报登记（各城市用的系统不同，例如 Kelowna 是 Alertable） | — |
| **信息不可信** | 群里说法互相矛盾 | 每条信息标来源和核实日期；不确定就说不确定 | — |

## 五、对开发和设计的要求

1. **按"我要办什么事"组织，而不是按机构组织**：办事卡是核心；地点是办事卡的落脚点。
2. **按他们的说法搜索**：六种语言的同义词、错别字、口语（"看病""换驾照""孩子上学"）；搜不到时给出下一步，而不是"没有结果"。
3. **手机优先、省流量、能离线**：单个文件、无需注册、无需下载 App；打开一次后没网也能用。
4. **不要求注册、不收集个人信息**：收藏和进度只存在自己手机里；隐私说明要和代码一致。
5. **写清楚"带什么、多少钱、等多久、谁能用"**：每张办事卡和关键地点都要回答这四个问题。
6. **安全内容永远一步可达**：求助按钮、24 小时热线、危机词搜索在任何语言下都能用。
7. **可信可见**：来源标签、核实日期、"大致位置""营业时间未知"如实显示。
8. **能分享到他们用的工具**：微信、WhatsApp、Facebook 群；链接要短、预览要好看。
9. **简单的英语也是一种语言**：英语版本用短句和白话；机构名和地址保持英文，方便对照路牌和表格。
10. **不替人做法律或移民判断**：给官方渠道和机构，不计算没有依据的期限、不判断资格。

## 六、对数据准备的要求

| 数据 | 为什么 |
|---|---|
| 服务对象（谁能用） | 身份决定资格 |
| 工作人员会的语言 | 打电话之前就知道能不能沟通 |
| 免费 / 补贴 | 钱紧 |
| 营业时间 | "现在能不能去" |
| 公交可达 | 没车 |
| 需要预约还是可以直接去 | 白跑一趟的代价很高 |
| 带什么证件 | 第一次去就能办成 |
| 当地叫法 | 搜索命中 |

每座城市每类数据的现状（已有、待收集）写在它的 PROFILE.md"对人群和需求的含义"一节。例如 Kelowna：见 `cities/kelowna/PROFILE.md`。

## 七、每座城市的特别之处

通用的人群和需求在第一至六节。每座城市由画像得出的特别之处（哪类人多、地理和交通的限制、房租与空置率、灾害、
家中常用语言）写在它的 `cities/<城市>/PROFILE.md` 的"对人群和需求的含义"一节，并说明对数据和设计意味着什么。
例如 Kelowna：见 `cities/kelowna/PROFILE.md`。

## 八、怎么验证这份判断

1. 请当地的安置机构、学区欢迎中心（SWIS）、高校国际学生办公室各看一遍，问："你们最常被问到什么？"（各城市找谁，写在其 PROFILE.md；例如 Kelowna：见 `cities/kelowna/PROFILE.md`）
2. 找 3–5 位不同身份的新到居民，看着他们用一次工具（不讲解），记录卡在哪里。
3. 上线后看访问记录：搜了没结果的词、打开最多的办事卡、从哪里来的访问。
4. 每座新城市把自己的人群特点写进它的 PROFILE.md"对人群和需求的含义"一节；只有对所有城市都成立的新发现才改这份文档。
