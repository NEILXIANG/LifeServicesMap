Privacy

This assistant is open to anyone, like the Kamloops Life Guide, but it is a separate tool with its own privacy note. It is independent — not a service of Kamloops Immigrant Services or the government.

  • Not collected: names, contact details, ID numbers, immigration status, health information. Please do not type these into a question.
  • Not stored: questions and answers are not written to any storage, and server logs do not record questions. The browser only remembers your interface language.
  • Sent to the AI service: only the question text and the relevant guide content, so that the AI can write the answer. The AI service is Anthropic’s Claude API; by default Anthropic does not train models on API data. Questions that look like a crisis are never sent to the AI — the page shows help lines instead.
  • Question limits: to keep the service free, each visitor can ask a limited number of questions per day. To count them we keep a one-way code made from your internet address and the date — not the address itself — and delete it after two days.
  • Anonymous feedback: “useful / wrong” and the one-sentence note on “wrong” (numbers and email addresses are removed).

Answers are compiled by AI from the guide and may contain errors; official sources take precedence. The assistant does not decide anyone’s immigration, legal or medical situation. In an emergency, call 9-1-1.

Le service d’IA est l’API Claude d’Anthropic ; par défaut, Anthropic n’entraîne pas ses modèles sur les données de l’API. Les questions qui semblent concerner une crise ne sont jamais envoyées à l’IA — la page affiche plutôt des lignes d’aide.

Privacidad

Este asistente está abierto a todos, como la Guía de vida en Kamloops, pero es una herramienta aparte con su propio aviso de privacidad. Es una herramienta independiente, no un servicio de Kamloops Immigrant Services ni del gobierno.

  • No se recopila: nombres, datos de contacto, números de identificación, estatus migratorio ni información de salud. No escriba estos datos en una pregunta.
  • No se guarda: las preguntas y respuestas no se almacenan en ningún lugar y los registros del servidor no contienen las preguntas. El navegador solo recuerda el idioma de la interfaz.
  • Lo que se envía al servicio de IA: solo el texto de la pregunta y el contenido relevante de la guía, para que la IA redacte la respuesta. El servicio de IA es la API Claude de Anthropic; de forma predeterminada, Anthropic no entrena modelos con datos de la API. Las preguntas que parecen una crisis nunca se envían a la IA: la página muestra líneas de ayuda.
  • Límite de preguntas: para que el servicio siga siendo gratuito, cada visitante puede hacer un número limitado de preguntas al día. Para contarlas guardamos un código de un solo sentido hecho con su dirección de internet y la fecha —no la dirección— y lo borramos a los dos días.
  • Valoraciones anónimas: «útil / incorrecta» y la frase que acompaña a «incorrecta» (se eliminan números y correos electrónicos).

Las respuestas las redacta la IA a partir de la guía y pueden contener errores; prevalecen las fuentes oficiales. El asistente no decide sobre la situación migratoria, legal o médica de nadie. En una emergencia, llame al 9-1-1.

隐私说明

本助手和 Kamloops 生活指南一样，任何人都可以使用；但它是一个单独的工具，有自己的隐私说明。它是独立制作的，不是 Kamloops Immigrant Services 或政府的服务。

  • 不收集： 姓名、联系方式、证件号码、移民身份、健康信息。请不要在提问里输入这些内容。
  • 不保存： 提问和回答的原文不写入任何存储，服务器日志也不记录提问内容。浏览器只记住你选的界面语言。
  • 发给 AI 服务的内容： 只有提问的文字，以及从生活指南里找到的相关内容，用来让 AI 写出回答。AI 服务是 Anthropic 的 Claude API；Anthropic 默认不用 API 数据训练模型。疑似危机的提问不会发给 AI，页面会直接显示求助电话。
  • 提问次数限制： 为了让服务保持免费，每位访客每天能问的次数有限。计数时我们只保存用你的网络地址和日期生成的单向编码（不保存地址本身），两天后自动删除。
  • 匿名反馈： "有用 / 有错"，以及"有错"时附的一句说明（程序会去掉其中的数字和邮箱）。

回答由 AI 根据指南整理，可能出错；重要信息请以官方来源为准。助手不对任何人的移民、法律或医疗情况下结论。紧急情况请拨 9-1-1。

개인정보 안내

이 도우미는 Kamloops 생활 가이드처럼 누구나 이용할 수 있지만, 별도의 도구이며 개인정보 안내도 따로 있습니다. 독립적으로 만든 도구로, Kamloops Immigrant Services나 정부의 서비스가 아닙니다.

  • 수집하지 않음: 이름, 연락처, 신분증 번호, 이민 신분, 건강 정보. 질문에 이런 내용을 입력하지 마세요.
  • 저장하지 않음: 질문과 답변 원문은 어디에도 저장되지 않으며, 서버 기록에도 질문 내용이 남지 않습니다. 브라우저는 선택한 화면 언어만 기억합니다.
  • AI 서비스로 보내는 내용: 답변을 쓰기 위한 질문 문장과 생활 가이드에서 찾은 관련 내용뿐입니다. AI 서비스는 Anthropic의 Claude API이며, Anthropic은 기본적으로 API 데이터로 모델을 학습시키지 않습니다. 위기로 보이는 질문은 AI로 보내지 않고, 대신 도움 전화번호를 보여 줍니다.
  • 질문 횟수 제한: 서비스를 무료로 유지하기 위해 방문자마다 하루에 할 수 있는 질문 수가 정해져 있습니다. 횟수를 세기 위해 인터넷 주소와 날짜로 만든 단방향 코드만 보관하며(주소 자체는 보관하지 않음), 이틀 뒤 자동으로 지웁니다.
  • 익명 의견: '도움 됨 / 틀림'과 '틀림'에 붙인 한 문장(숫자와 이메일 주소는 지웁니다).

답변은 AI가 가이드를 바탕으로 정리한 것이라 틀릴 수 있으며, 공식 출처가 우선입니다. 도우미는 누구의 이민·법률·의료 상황에 대해서도 결론을 내리지 않습니다. 응급 상황에서는 9-1-1에 전화하세요.

プライバシー

このアシスタントは Kamloops 生活ガイドと同じく誰でも使えますが、別のツールで、プライバシーの説明も別にあります。独立したツールで、Kamloops Immigrant Services や政府のサービスではありません。

  • 収集しないもの： 氏名、連絡先、身分証の番号、在留資格、健康情報。質問にこれらを入力しないでください。
  • 保存しないもの： 質問と回答の本文はどこにも保存せず、サーバーの記録にも質問は残りません。ブラウザが覚えるのは画面の言語だけです。
  • AI サービスに送る内容： 回答を作るための質問の文と、生活ガイドから見つけた関連する内容だけです。AI サービスは Anthropic の Claude API で、Anthropic は初期設定では API のデータでモデルを学習しません。危機に関わると思われる質問は AI に送らず、代わりに相談電話を表示します。
  • 質問回数の制限： 無料で続けるため、1人が1日にできる質問の数を限っています。数えるために、インターネットのアドレスと日付から作った一方向のコードだけを保存し（アドレスそのものは保存しません）、2日後に自動で削除します。
  • 匿名の評価： 「役に立った / 誤りがある」と、「誤りがある」に添えた一文（数字とメールアドレスは削除します）。

回答は AI がガイドをもとにまとめたもので、誤りがある場合があります。公式の情報源が優先です。このアシスタントは、誰の在留・法律・医療の状況についても結論を出しません。緊急時は 9-1-1 に電話してください。
