> （直接复制用户原话，加引号）

**我提炼的诉求**：

- （用一句话说清楚用户实际想要什么）

**信号强度**：⭐ / ⭐⭐ / ⭐⭐⭐ / ⭐⭐⭐⭐
（⭐ = 随口一提；⭐⭐ = 主动发来；⭐⭐⭐ = 反复出现；⭐⭐⭐⭐ = 多个用户独立提到同一件事）

**是否转化为行动**：是（→《数据质量日志》/《业务假设》） / 否 / 待定
