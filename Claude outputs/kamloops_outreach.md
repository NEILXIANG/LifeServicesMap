# 可以推广"生活指南"的 Kamloops 机构名单

日期：2026-09-15 · 数据来源：应用自己已核实的地点库（`data-kamloops.js`）+ 补充核实的三个未收录联系方式（TRU World、SWIS 项目、bc211 上架渠道、TNRL 总部）

**怎么用这份名单**：不是"推广"，是"让每天被问路的人手里有个链接可以发"（你自己在 09-10 那份传播方案里定的调子，这份名单沿用同一逻辑）。给每家发一封两段话的邮件——这是什么、为什么免费、附上一个能直接打开的深链接（比如 `?task=connect` 而不是整个网站）——不求他们主动推广，只求下次有人问的时候，他们手边有这个。

## 建议的联系顺序

1. **Kamloops Immigrant Services** 先联系——他们已经是应用里权重最高的机构，而且这次刚好新加了直接引用他们三个项目（英语角、SWIS、SPOKE）的内容，是最自然、最有说服力的开场（"我不只是提到你们，我核实过你们具体在做的项目"）。
2. **两家图书馆 + TNRL 总部**——传单/名片卡最理想的落地点，成本最低（一封邮件）。
3. **食物银行、法律诊所、庇护所类**——这些机构的接待员每天都在被问"我该去哪"，是最高频的转发者。
4. **TRU World、SD73**——覆盖国际学生和有孩子的家庭这两类和"新移民"部分重叠但不完全一样的人群。
5. 政府窗口类可以往后放，或者换一个诉求——不是"帮我推广"，而是"如果你们的新居民资源页面愿意链接，这是一份多语言、逐条核实的第三方指南"（这一条在你 09-10 的传播方案里也提到过，官方机构愿意链接的是"引用了他们并且写对了"的页面）。
