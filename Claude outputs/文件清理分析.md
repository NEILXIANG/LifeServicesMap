## 〇、先说一个不属于清理范畴、但需要立刻处理的问题

**隐私声明漏掉了一个真实存在的第三方请求。** `src/engine.html:3307` 有一行在运行的
Cloudflare Web Analytics beacon：

```html
<script type='module' src='https://static.cloudflareinsights.com/beacon.min.js'
        data-cf-beacon='{"token": "dfb57b0791..."}'></script>
```

而我昨天改写的隐私声明写的是「另一类对外请求是地图底图」——**把它说成了唯一的另一类**。
实际上每次打开页面还会向 `static.cloudflareinsights.com` 发一次请求（对方因此能看到访问者 IP）。
这是我改写时的疏漏，不是你原有的问题。它同时意味着：

- 页面上**同时跑着两套统计**：Cloudflare Web Analytics（2026-09-04 接入）+ 自建 `/api/event`
  （Phase A 自建 Worker，产物里出现 10 处）。两者功能重叠。
- 构建产物里因此有一个**外部 script 标签**，与「单文件自包含、断网可用」的设计前提相抵触
  （Leaflet 当初专门内联就是为了这个）。断网时它只是加载失败，不影响功能，但性质变了。

要么在隐私声明里补上这一句，要么删掉这个 beacon（自建埋点已经覆盖了它的用途）。两者都是一行改动，
你决定哪个方向，我来改。
