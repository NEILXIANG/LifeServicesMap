# tests/kelowna/ — Kelowna 的界面回归

Kelowna 还是草稿（`city.json` 里 `"status": "draft"`），这里的测试保证"草稿就算被人打开，也不会给出错的东西"。
断言里用到 Kelowna 的真实地点（三家 UPCC、RCMP 电话），只对 `build/kelowna.html` 有意义（测试会先自己构建）。

全部运行：`./scripts/check-all.sh`（会自动跑每座城市的 `tests/<城市>/guitest.py`）。

| 文件 | 覆盖内容 |
|---|---|
| `guitest.py` | 2026-10-04 严格界面测试，约 80 项：六种语言下页面、指南、帮助、分享、全部地点弹窗、公交面板里**不出现任何 Kamloops 事实**（地名、电话、票价、"Google Places"）；没有未替换的占位符、`undefined`、`NaN`；全部弹窗能打开、电话链接能拨；六种语言的常用搜索都有结果；搜"看病"列出三家 UPCC，"在地图上看"在先搜过几次之后也能打开、并且卡片保持打开（这一项抓到过引擎 bug，Kamloops 也有，2026-10-04 修复）；危机词直接给热线；每个分类、每个区域都有地点；"现在营业""附近"可用（附近先弹说明）；17 张办事卡六种语言都能打开、链接有效；29 条公交线路都能选中；收藏和语言在刷新后保留；320–1280 像素宽度下页面和指南都没有横向滚动；按钮都有可读名称；整个过程没有页面错误 |

跑测试时从本地文件打开页面，地图底图的密钥只允许正式网址，统计信标也没有来源，所以这两类网络拒绝会被忽略（引擎会自动换备用底图）；其他任何控制台错误都算失败。
