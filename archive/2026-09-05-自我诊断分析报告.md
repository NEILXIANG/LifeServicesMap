## 1. UI 与视觉设计

### 1.1 视觉系统（强项）
- **配色**：单一主色（`--accent:#1a73e8` Material blue），语义色（sage/绿）、sub-ink（灰 5f6368）、line（daece0）—— **极简一致**
- **字体回退链**：`--apple-system, ..., "PingFang SC", "Microsoft YaHei", "Apple SD Gothic Neo", "Malgun Gothic", "Noto Sans CJK SC"` —— **CN/JP/KR 三语系齐备**（`engine.html:16-17`）
- **触控尺寸**：`.lang-btn` 在 `pointer:coarse` 时 `min-width:44px`（`engine.html:322-329`），符合 WCAG 2.5.5
- **感知性**：尊重 `prefers-reduced-motion`（`engine.html:339`）

| LOG-06 | **P2** | 双 `tabs` 开同一页面会生成 2 个 sid，但不可分辨 | localStorage 是 origin-级共享 | 同一访客跨标签行为不可分 | 加 tab ID 到 sid 段，或加 `tab_id` props |

### 3.3 查询分析工具链（强项）
- `query-events.py`（按 Phase A 改造后）12 预设（health/types/funnel/gap/daily/lang/places/presets/routes/recent/session/--list）
- **已发现 Analytics Engine SQL API 限制**（手册 §8 已更新）：
  - ❌ `uniq()` 函数不可用 → 全用 `count(DISTINCT col)`
  - ❌ `JSONExtractString()` 不可用 → places/presets/routes 后处理 blob3 JSON

## 12. 扩展性

| 维度 | 现状 | 下个城市（如 Kelowna）成本 | 评级 |
|---|---|---|---|
| 数据扩展 | `src/data-<city>.js` + `build.py --city X` | 一个数据文件 + `python3 build.py --city X` | 🟢 优 |
| 引擎扩展 | `engine.html` 已 2997 行，category/group/icon 全 hardcoded 在引擎里，**新分类要改引擎** | 加 1 个分类 = 改 4 个文件 | 🟡 中 |
| 语言扩展 | `UI.<lang>.xxx` 模板要逐句写 5 倍 | 加 1 个语言 = 156 个键 × 30+ 函数 | 🟠 重 |
| RTL 扩展 | 0 准备 | 完全重做 CSS direction | 🔴 不可用 |
| 主题扩展 | 单主题（仅浅色） | 加 dark mode = 写 :root vars × 2 + prefers-color-scheme | 🟡 中 |
| 实时数据接入（GTFS/transit live） | 无 | 需要 fetch 第三方 + 重写 renderRoute | 🟠 重 |
| 移动 App / PWA | 无 manifest.json、无 SW | 一次性工作 ~半天 | 🟢 优 |

**结论**：当前架构对"加新城市"友好；**对"加新语言/RTL/插件"不友好**。
